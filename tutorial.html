Configuração dos vídeos locais no Django

Para que os vídeos funcionem corretamente, siga estas etapas no seu projeto Django:

  1. Crie a pasta media/videos/ na raiz do seu projeto (ao lado do manage.py).
  2. Adicione os arquivos de vídeo com os nomes:
    introducao.mp4, cadastro_cliente_produtos.mp4, tabela_nutricional.mp4, ingredientes.mp4, etiquetas_rotulos.mp4.
  3. No settings.py, configure:
    MEDIA_URL = '/media/'
    MEDIA_ROOT = BASE_DIR / 'media'
  4. No urls.py (apenas desenvolvimento), adicione:
    + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
  5. Se quiser uma imagem de thumbnail (poster), coloque arquivos .jpg com os mesmos nomes + _thumb (ex: introducao_thumb.jpg) na mesma pasta.
Importante: Em produção, use um servidor web (Nginx, Apache) para servir os arquivos de mídia. Nunca confie no runserver para produção.
